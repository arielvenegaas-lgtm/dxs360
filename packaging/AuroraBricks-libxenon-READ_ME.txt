Aurora Bricks (libXenon build) - Xbox 360 bare-metal homebrew
=============================================================

FILE: AuroraBricks.elf

HOW TO PLAY (RGH/JTAG console with Aurora installed):
  1. Copy this folder (AuroraBricks) to any storage the console can read
     (USB stick, HDD, or your Aurora content drive).
  2. Launch Aurora.
  3. Open the File Manager and browse to AuroraBricks/AuroraBricks.elf.
  4. Press A to run it.

CONTROLS:
  Left stick / D-pad  : move paddle
  A                   : launch ball / advance / restart
  Start               : pause
  (With no controller connected the game plays a demo by itself.)

NOTES:
  - This is a libXenon "ELF" title, NOT a signed .xex. It runs from Aurora's
    File Manager (or from XeLL). It is open-source and built in GitHub Actions
    via the free60/libxenon toolchain - no Microsoft XDK is used.
